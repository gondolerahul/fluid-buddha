# FluidBuddha with Google Tag Manager

## A. Custom template (recommended)

GTM only lets a template add scripts from addresses it declares, so the template is
generated by your FluidBuddha server, for that server:

1. Download it: the console's **Install → Google Tag Manager → Download template**,
   or `https://<your-server>/widget/gtm-template.tpl`.
2. In GTM: **Templates → Tag Templates → New → ⋮ → Import**, choose the file, **Save**.
   (Its **Tests** tab has GTM tests you can run there.)
3. **Tags → New → Tag configuration →** *FluidBuddha AI agent*. Paste your **widget
   key** (`fbk_…`, from the console), optionally pick position and language.
4. **Triggering → All Pages** (or *Initialization – All Pages*). Save, **Preview**, then
   **Submit**.

The template asks for one permission: to inject
`https://<your-server>/widget/loader.js`. Nothing else (no cookies, globals or data
layer access).

The server writes its own address into the template from `PUBLIC_API_URL`, so set
that correctly before downloading (see `backend/.env.example`).

## B. Custom HTML tag

1. **Tags → New → Custom HTML**, paste the snippet from the console's Install tab:

   ```html
   <script src="https://<your-server>/widget/loader.js" data-key="fbk_…" async></script>
   ```

2. Trigger on **All Pages**, save, preview, submit.

## Goals for A/B tests

Once the agent is loaded, a GTM Custom HTML tag fired on your goal (e.g. a
"thank you" page or a form-submit trigger) can report it:

```html
<script>window.FluidBuddha && window.FluidBuddha.conversion('demo_booked');</script>
```

## Publishing to the Community Template Gallery

The gallery takes a template from a public GitHub repository (a `template.tpl` plus
`metadata.yaml`). Generate `template.tpl` from the production server
(`/widget/gtm-template.tpl`) so its permission names the production address, and
submit it from the repository's owner account.
